Step 2 of 2 — Add your Wix code

This code tells your Wix site to notify AccessSync when a member joins or cancels. Paste it once and you're done — no updates needed.

  1. In your Wix Editor, click Dev Mode in the top menu bar to enable it
  2. Go to Dashboard → Developer Tools → Secrets Manager and add a new secret:
    • Name: accesssync_webhook_secret
    • Value: a secure random string (at least 32 characters — use a password generator)
    • Then share this same secret with your AccessSync admin so they can verify incoming webhooks.
