Environment Variables — Core Engine (node server.js)
VariableDescription
DATABASE_URL Required PostgreSQL connection string (Railway). Set automatically by Railway Postgres plugin.
WIX_WEBHOOK_SECRET Required HMAC secret from Wix developer dashboard. Used by wix-connector.js to verify all inbound webhooks (DR-009).
KISI_ENCRYPTION_KEY Generate 32-byte hex string for AES-256-GCM encryption of hardware API keys (DR-028). Generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
RESEND_API_KEY Required Resend API key from resend.com dashboard. Required for all operator email notifications (DR-020). OB-51 open.
RESEND_FROM_EMAIL Required Sender address for all Resend emails — e.g. alerts@accesssync.io. Must be a verified Resend domain.
ACCESSSYNC_OWNER_NOTIFICATION_EMAIL Required Platform owner email (Daxx). Receives HMAC spike alerts, reconciliation digests, and acts as client notification fallback when a client has no notification_email set. Set once per Railway deployment. This is NOT per-tenant — each gym operator sets their own via the Platform Config UI (clients.notification_email).
PORT Set automatically by Railway. Do not set manually.
NODE_ENV development | production. Set to production on Railway.
DEFAULT_TENANT_ID Temporary single-tenant fallback. Remove when multi-tenant routing is complete (site_id self-registration via tenant-resolver.js).
Environment Variables — Admin Hub (node admin/server.js)
VariableDescription
ADMIN_JWT_SECRET Generate Random 64-character string — JWT signing secret for admin sessions. Generate: node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
GOOGLE_CLIENT_ID Required OAuth 2.0 Client ID from Google Cloud Console. Public value — safe to expose. Enable Google Identity Services for the Admin Hub domain.
ADMIN_ALLOWED_EMAIL Required daxxroberts@gmail.com — only this Google account can log in to the Admin Hub. Hard allowlist — not a role, not a flag.
OWNER_PIN Generate Owner bypass PIN for onboarding Step 4. Allows location activation without a Kisi key (demo/testing). Short numeric PIN stored in Railway Admin Hub service vars.
OPERATOR_INVITE_TOKEN Generate Shared secret protecting onboarding signup endpoints (OB-24). Operator receives link with ?invite=TOKEN. Generate: node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"
CORE_ENGINE_URL Required Core Engine Railway URL — used by onboarding Step 5 validation. e.g. https://accesssync.up.railway.app. OB-25 open.

FileWhat it doesStatus
schema.sql 14-table baseline schema. Run once on fresh DB. Note: shows kisi_api_key — DR-035 renames after this runs. ✓ Baseline

migrations/sprint-5.sql Sprint 5 columns: locations.hardware_key_last_verified (TIMESTAMPTZ), locations.hardware_key_last_error (TEXT), clients.first_grant_sent (BOOLEAN DEFAULT false). Required before Sprint 5 code deploy. ⚠ Pending (Daxx)
