port 3000 — webhook processor, member sync API, health check
POST
/webhooks/wix
All inbound Wix events — plan.purchased, plan.cancelled, payment.failed, payment.recovered, member.deleted, booking.confirmed, booking.cancelled. HMAC-verified, queued to BullMQ immediately.
HMAC
GET

Wix JWT

/health
Railway health check — returns {"status":"ok"}. Required for Railway to detect the service is running.
