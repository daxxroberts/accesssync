Core Features — Single Member Access
ID Feature Description Status Related
F001 Plan-to-Group Grant Wix plan.purchased → Kisi group role assignment via 7-layer pipeline Live DR-022, SPEC_V1_Core_Flow
F002 Plan Revoke Wix plan.cancelled → delete Kisi role assignment Live SPEC_V1_Core_Flow
F003 Payment Suspension Wix payment.failed → Kisi access_enabled: false (user-level, preserves role assignments) Live SPEC_V1_Core_Flow
F004 Payment Recovery Wix payment.recovered → Kisi access_enabled: true. enableAccess only — no new role assignments (DR-026) Live DR-026
F005 Member Deletion Wix member.deleted → DELETE Kisi user entirely Live SPEC_V1_Core_Flow
F006 Webhook Deduplication processed_event_ids table prevents double-processing. Event ID checked before BullMQ enqueue. Live DR-010
F007 Identity Resolution Wix member → Kisi user lookup/create chain. Platform-agnostic (DR-021). DB cache → findUserByEmail → createUser. Live DR-021, DR-023
F008 Multi-Door Provisioning Single plan maps to multiple Kisi groups. member_role_assignments table stores one row per door per member. Live DR-026
F009 Multi-Source Grant/Revoke member_access_sources table tracks all reasons a member is in a group. Pre-grant check. Revoke only when zero sources remain. Prevents time-limited booking from overwriting permanent plan access. Planned DR-034
F010 Nightly Reconciliation Scheduled sync: AccessSync ↔ Kisi state comparison, drift correction. Stale lock cleanup, failed job re-queue, operator digest. Live SPEC_Nightly_Reconciliation
Core Features — Multi-Member / Family Plan
ID Feature Description Status Related
F020 Sub-Member ID Generation Synthetic ID format: {uuid}###as{NNN}. Deterministic, reversible, collision-free. Exploded from Wix plan_members event in Layer 2. Planned DR-029
F021 Plan Holder Linkage plan_holder_id column links sub-members to primary Wix member. NULL for single-plan and event-booking members. Planned DR-030
F022 Upstream Explosion Family plan webhook exploded into synthetic single-member events in Wix Adapter (L2). Core Engine grant/revoke path unchanged. Planned DR-031
F023 Draft-Submit Workflow Operator/plan holder adds sub-members in draft state, reviews, then submits batch. No access provisioned until submit. Planned DR-032
F024 Unified Member Widget Single HTML screen handles single plan, event booking, and family plan modes. planType param controls visible sections. Planned DR-033
F025 Family Suspension payment.failed suspends plan holder + all linked sub-members atomically Planned DR-030
F026 Family Revoke Cascade plan.cancelled or holder deleted → revoke all sub-members for that plan Planned DR-030

Integration Features
ID Feature Description Status Related
