AccessSync · Product Overview

Automated Access Control for Gym Operators

When a member buys a plan on your Wix site, AccessSync automatically provisions their door access in Kisi. No manual steps. No chasing spreadsheets.

Webhooks — Wix fires events whenever a plan is purchased, renewed, cancelled, or a member is removed

The Connector
AccessSync
Translates plans into door permissions
Plan Mapping — you define which Wix plan maps to which Kisi door group
Grant & Revoke — when a member buys, access is granted; when they cancel, it's removed automatically
Error Recovery — failed jobs are retried with exponential backoff and surfaced in a nightly digest
Operator Console — dashboard, member list, access log, and location management in one place

Your Door System
Kisi
Smart locks and mobile access credentials
Users — each gym member becomes a Kisi user with a mobile credential tied to their email
Groups — a group is a set of doors; assigning a member to a group gives them access to every door in it
Role Assignments — the link between a user and a group; AccessSync creates and deletes these automatically
Lockdown — when a door is in lockdown, AccessSync detects it and skips provisioning until it clears
How It Works — Four Steps
1
Member Buys a Plan
A gym member completes checkout on your Wix site. Wix fires a plan.purchased or booking.confirmed webhook to AccessSync within seconds.
Wix Event
2
AccessSync Processes It
The webhook is verified (HMAC signature), deduplicated, and queued. AccessSync looks up which Kisi group the plan maps to and locks the member record to prevent concurrent conflicts.
Core Engine
3
Kisi Account Provisioned
AccessSync creates the member in Kisi (if they don't exist), then assigns them to the mapped group. The member instantly receives a mobile credential via the Kisi app — no email sent from Kisi.
Kisi API
4
Access Stays in Sync
Renewals keep access active. Cancellations remove it. Plan upgrades add new door groups. Member deletions remove the Kisi user entirely. Every change is handled without operator action.

Before and After AccessSync
Without AccessSync
Member buys a plan online → staff gets a notification → someone has to log into Kisi → manually create or update the user → assign them to the right group → hope they got it right
Member cancels → plan lapses → staff has to remember to remove Kisi access → often forgotten → ex-members walk in for months
New staff member doesn't know the process → member shows up at 5am → door doesn't work → angry text to the owner
No audit trail → who has access to which doors? → check Kisi manually → doesn't match what's in Wix
With AccessSync
Member buys a plan online → Kisi user created and assigned to the correct group automatically within seconds → member opens the app and walks in
Member cancels → webhook fires → role assignment removed from Kisi immediately → access gone the same day, no manual step
Staff doesn't need to touch Kisi at all → AccessSync handles every new signup, upgrade, downgrade, and cancellation
Operator console shows every member, their access state, which doors they're assigned to, and a full event history
